# Description
KDR-PE offers developers a simple, easy to read API. Here you can find how to obtain a player kills, killstreak and death, ect.

Look down below for examples.

# Obtain KDR/Database instance
**To obtain the database instance you must do the following:**
```php
// Import this class
use terpz710\kdrpe\database\Database;

// Create a variable (optional)
$DBinstance = Database::getInstance();

// Now you can use '$DBinstance' as the Database instance

// THATS IT!
```

**To obtain the KDR instance you must do the following:**
```php
// Import this class
use terpz710\kdrpe\api\KDR;

// Create a variable (optional)
$KDRinstance = KDR::getInstance();

// Now you can use '$KDRinstance' as the KDR instance

// THATS IT!
```
