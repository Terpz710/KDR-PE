# Installation guide:
**Step 1:**
Download the `KDRScoreTag.phar`

**Step 2:**
Move the .phar to the `plugins` folder within your server's directory

**Step 3:**
Start your server and enjoy!

# How to configure ScoreHud?
Head over to the folder `plugin_data` and go inside `ScoreHud`.

From there you will see a .yml file called `scoreboard.yml`

Click on it and you'll see the different options.

Just like ScoreHuds built in tags KDR-PE is the same.
